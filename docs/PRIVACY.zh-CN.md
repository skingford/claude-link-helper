# Link Helper for Claude — 隐私政策

[English](PRIVACY.md) | **简体中文**

生效日期：2026 年 10 月 3 日

Link Helper for Claude 是通过[项目仓库](https://github.com/skingford/claude-link-helper)维护的独立浏览器扩展，与 Anthropic 无隶属关系，也未获得其背书。

## 扩展访问哪些信息

扩展会检查已配置邮箱网站中呈现的网页内容，包括邮件文字、按钮文案和超链接。对于其他网站，仅在你通过扩展弹窗选择「检测当前页面」后运行。这些访问仅用于查找和校验 Claude 邮件登录链接。

登录链接可能包含一次性身份验证 token 和经过编码的账户信息。扩展将它们作为敏感数据处理，仅用于检测和复制功能，不会打开登录链接或用它登录账户。

## 信息如何使用

所有处理均在你的设备上完成。扩展检查按钮文案和 URL 结构，识别多个链接或无法验证的链接，并显示结果。临时数据只存在于当前页面或弹窗的内存中；扩展不会将邮件正文或登录链接保存到浏览器存储或数据库。

弹窗初次检测只接收数量和不含凭据的修订编号。当你明确点击弹窗中的复制按钮时，重新校验的链接才会在本地从页面脚本传给弹窗，并写入剪贴板。邮件正文旁的工具条同样需要点击才会复制。

## 网络访问、共享和追踪

扩展不会将邮件内容、登录链接、身份验证 token 或使用数据发送给开发者或任何服务器。扩展不包含分析统计、广告、追踪 SDK、远程脚本或远程图片依赖，不出售、共享用户数据，也不将其用于广告、画像或模型训练。

已支持的跳转包装仅在本地解码。扩展不会访问追踪链接或跟随跳转来确认目标地址。

邮箱服务商、Google Chrome、Chrome 应用商店和操作系统独立于本扩展运行，其行为受各自的隐私政策约束。

## 剪贴板

扩展申请剪贴板写入权限，不申请剪贴板读取权限。只有点击复制按钮时，登录链接才会被写入剪贴板。

复制后，链接可能保留在系统剪贴板或剪贴板历史中。操作系统提供的剪贴板同步由系统设置控制。你可以使用正常的剪贴板操作替换或清除已复制的内容。

## 权限用途

| 访问范围或权限 | 用途 |
| --- | --- |
| 已列出的邮箱网站 | 在呈现的邮件页面中检测登录链接，并在支持的位置自动显示助手 |
| `activeTab` | 临时检查你主动执行手动检测的页面 |
| `scripting` | 在该页面运行随扩展打包的检测脚本 |
| `clipboardWrite` | 在点击后复制选定的登录链接 |

## 你的选择与保留期限

你可以在 Chrome 中限制扩展的网站访问权限、使用手动检测、禁用扩展或卸载扩展。刷新或关闭页面、弹窗会丢弃该文档的临时处理状态。开发者没有保存你的邮件或登录链接副本，因此也没有可供检索或删除的此类数据。卸载扩展不会清除之前已经复制到系统剪贴板中的内容。

数据仅用于已经披露的登录链接检测和复制功能。扩展的数据使用遵循 Chrome 应用商店用户数据政策及其 Limited Use（受限使用）要求。

## 联系与更新

隐私问题可发送至 [aisolocode@gmail.com](mailto:aisolocode@gmail.com)，或提交到[项目问题追踪页](https://github.com/skingford/claude-link-helper/issues)。请勿在公开问题中包含真实登录链接、token 或私人邮件内容。

如果数据处理方式发生变化，本政策将更新生效日期，相关变化也会同步到扩展的商店披露信息中。
